# 프로젝트 원본 자동 복구

## 상태

- 구현 및 자동 검증 완료

## 저장 규칙

- 프로젝트 자산으로 복사한 PSD는 `psd/<파일명>`, Audio는 `audio/<파일명>` 상대경로를 Source locator에 저장한다.
- `.ziq`에는 상대경로와 파일명뿐 아니라 SHA-256 파일 지문과 바이트 크기를 함께 저장한다.

## 열기 규칙

1. 현재 세션에 유효한 원본 파일 handle을 먼저 사용한다.
2. handle이 없으면 프로젝트 폴더 선택을 한 번 요청한다.
3. 저장된 상대경로의 파일을 먼저 확인하고 파일 지문을 대조한다.
4. 실패하면 종류에 따라 `psd/` 또는 `audio/` 폴더를 훑어 같은 파일 지문의 원본을 찾는다.
5. 두 단계 모두 실패한 Source만 `missing`으로 표시한다.

## 검증

- 상대경로의 동명 파일 지문이 다를 때 그대로 연결하지 않는다.
- 파일명이 바뀌었어도 폴더 안에서 지문이 같은 파일을 찾아 복구한다.
- 폴더에도 일치 파일이 없을 때만 `null`을 반환한다.
