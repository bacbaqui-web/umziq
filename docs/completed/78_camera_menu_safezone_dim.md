# 촬영범위 메뉴에 세이프존과 바깥 어둡기 통합

## 완료 결과

- 상단 도구 모음의 독립 `세이프존` 버튼을 제거했다.
- `촬영 범위` 드롭다운 안에서 세이프존 표시 여부를 전환한다.
- 같은 메뉴에 `바깥 어둡기` 0~100% 슬라이더를 추가했다.
- 세이프존의 기본값은 `보임`, 바깥 어둡기의 기본값은 50%다.
- 마스크 렌더링은 고정 알파값 대신 선택한 어둡기 값을 사용한다.
- 값은 `projectId`별 Canvas View 설정으로 저장되어 다른 프로젝트와 섞이지 않는다.

## 검증

- Canvas Guide ViewModel이 0~100%로 정규화한 값을 Preview Guide에 전달한다.
- TypeScript, ESLint, 전체 QA와 `git diff --check`로 회귀를 확인한다.
