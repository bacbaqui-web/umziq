# 중앙 원점 좌표계

## 상태

- 구현 및 자동 검증 완료

## 목적

사용자가 보는 위치 좌표는 활성 그룹의 정중앙을 `(0, 0)`으로 사용한다.

## 규칙

- 오른쪽은 `+X`, 아래쪽은 `+Y`다.
- 저장·렌더 내부 좌표는 기존 파일 호환을 위해 유지한다.
- Properties 위치 입력과 위치 키프레임은 중앙 원점 좌표로 읽고 쓴다.
- 캔버스 핸들 이동 뒤 표시되는 위치도 같은 중앙 원점 좌표를 사용한다.
- 기준점(anchor)은 레이어 내부의 회전·크기 기준이라는 기존 의미를 유지한다.

## 호환성

- 기존 `.ziq` 파일을 다시 저장하거나 마이그레이션하지 않아도 화면 위치가 바뀌지 않는다.
- 부모 그룹의 캔버스 중앙을 변환 경계로 사용하므로 중첩 그룹에서도 같은 규칙을 적용한다.

## 검증

- 기존 PSD Properties 통합 검증에 중앙 좌표 읽기·입력·키프레임 저장 회귀 검증을 추가했다.
