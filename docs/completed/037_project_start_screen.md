# 프로젝트 시작 화면과 강제 폴더 구조

## 목표

움직을 실행하자마자 이름 없는 편집 상태로 들어가지 않고, 모든 작업이 파일로 저장되는 프로젝트 안에서 시작되게 한다.

## 완료 결과

- 프로젝트가 열리지 않은 상태에는 편집기 전체를 덮는 시작 화면이 표시된다.
- 시작 화면과 프로젝트 대화상자는 `document.body` 최상위 Portal에 표시되어 상단 Grid item의 stacking context에 갇히지 않는다.
- 따라서 화면 중앙 정렬은 전체 viewport를 기준으로 하며 캔버스 가이드와 조작 UI가 시작 화면 위로 새지 않는다.
- 시작 화면 배경은 편집기 형태가 은은하게 비치는 반투명 어둠과 1px 블러를 사용한다.
- 시작 카드는 화면 상단에서 200px 떨어진 위치에 배치한다.
- 새 프로젝트와 프로젝트 열기는 동일한 색상의 세로형 선택 카드로 표시하며 각각 큰 `+` 아이콘과 폴더 열기 아이콘을 사용한다.
- 시작 선택 화면에서는 별도의 `움직`, `숏폼 애니 제작기` 제목을 표시하지 않는다.
- 시작 화면에는 `새 프로젝트`, `프로젝트 열기` 두 동작만 제공한다.
- 새 프로젝트 창에서 프로젝트 이름과 저장할 상위 위치를 모두 정해야 생성할 수 있다.
- 생성 시 선택 위치 아래에 프로젝트 이름의 전용 폴더를 만들고 다음 항목을 자동 생성한다.
  - `<프로젝트 이름>.ziq`
  - `psd/`
  - `audio/`
- 같은 프로젝트 폴더에 기존 `.ziq`가 있으면 덮어쓰지 않고 다른 이름을 사용하도록 안내한다.
- 프로젝트 열기는 선택한 폴더의 유일한 `.ziq`를 자동으로 열고 같은 폴더를 자산 루트로 사용한다.
- 프로젝트를 닫으면 다시 시작 화면으로 돌아간다.
- File System Access API를 제공하지 않는 브라우저의 기존 파일 열기 fallback은 유지한다.

## 검증

- 생명주기 UI 검증에 시작 화면, 두 진입 동작, `psd/`, `audio/` 생성 계약을 추가했다.
- 프로젝트 폴더 선택을 기존 열기 어댑터로 전달하는 Runtime 계약을 유지한다.
- 전체 `npm run qa`와 `git diff --check`로 회귀를 확인한다.
