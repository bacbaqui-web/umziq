# PSD 그룹 콘텐츠 중앙 기준점

## 상태

- 구현 및 자동 검증 완료

## 결과

- PSD를 처음 불러올 때 그룹 기준점은 원본 캔버스 중앙이 아니라 자식 픽셀 레이어 전체를 감싸는 영역의 중앙에 놓인다.
- 중첩 그룹과 PSD 최상위 그룹에 같은 규칙을 적용한다.
- 숨겨진 레이어도 나중에 다시 표시할 수 있는 그룹 콘텐츠이므로 계산에 포함한다.
- 빈 그룹만 원본 캔버스 중앙을 안전한 기본값으로 사용한다.
- 기준점만 바뀌며 초기 이미지 배치는 움직이지 않는다.

## 검증

- 서로 다른 위치와 크기의 일반 레이어·중첩 레이어를 가진 PSD fixture에서 그룹별 콘텐츠 중앙값을 검증한다.
