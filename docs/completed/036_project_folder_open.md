# 프로젝트 폴더 한 번으로 열기

## 사용자 문제

`.ziq` 파일을 고른 뒤 연결 소스를 찾기 위해 같은 폴더를 다시 고르는 흐름이 반복됐다.

## 완료 결과

- `열기`는 지원 브라우저에서 프로젝트 폴더를 한 번 선택한다.
- 선택한 폴더 루트에 `.ziq` 파일이 하나 있으면 앱이 자동으로 읽어 프로젝트를 연다.
- 같은 디렉터리 핸들을 프로젝트 자산 루트로 유지하므로 `psd/`, `audio/` 복구 과정에서 폴더 선택 창을 다시 띄우지 않는다.
- `.ziq`가 없거나 여러 개면 잘못된 프로젝트를 임의로 열지 않고 안내한다.
- File System Access API가 없는 브라우저는 기존 `.ziq` 파일 선택 방식으로 돌아간다.

## 검증

- 폴더에서 준비한 프로젝트 선택이 기존 파일 선택 창을 건너뛰는 어댑터 계약을 `verifyLayerDocumentProjectOpen.ts`에 추가했다.
- TypeScript build 및 전체 QA로 확인한다.
