# 촬영범위 바깥 전체 어둡게 표시

## 문제

촬영범위 바깥 마스크가 프로젝트의 미리보기 월드 크기까지만 생성되어, 더 멀리 떨어진 캔버스 공간에는 투명한 빈 영역이 보였다.

## 완료 결과

- 촬영범위 마스크를 프로젝트 캔버스 크기로 제한하지 않는다.
- 촬영범위의 위, 아래, 왼쪽, 오른쪽 네 영역을 충분히 큰 월드 범위까지 확장한다.
- 확대, 축소, 이동을 해도 촬영범위 안쪽만 원래 화면으로 보이고 그 밖의 모든 영역에는 기존 반투명 검정 마스크가 유지된다.
- 촬영범위와 세이프존의 좌표 계산 방식은 변경하지 않는다.

## 검증

- TypeScript 검사와 전체 QA로 Canvas Guide 회귀를 확인한다.
