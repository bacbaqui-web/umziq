# 다음 Sprint 초안

> 상태: 미정

현재 승인된 다음 제품 Sprint는 없다.

새 기능이나 구조 작업을 시작할 때 다음 항목만 이 문서에 작성한다.

- 해결할 사용자 문제
- 관련 canonical Architecture
- 범위와 금지 사항
- 검증 가능한 완료 조건
- 현재 Sprint인 `docs/98_sprint_plan.md`로 승격할 조건

완료된 Nexus·Gateway·Editor Root·Engine 재구성 과정은
`docs/completed/057_architecture_contract_regression_baseline.md`부터
`docs/completed/068_documentation_architecture_cleanup.md`까지 보존한다.
