모든 Engine 연결 지점

사용자가 버튼을 누르거나 마우스를 움직이면 가까운 UI Engine이 먼저 요청을 받습니다. 프로젝트 문서 변경은 Project Engine, 시간에 따른 값 변경은 Animation Engine, 현재 프레임과 완성 화면 만들기는 Playback & Render Engine이 맡습니다. 계산이 끝나면 UI Engine이 결과를 받아 다시 화면에 보여줍니다.

예시 1 · Canvas에서 레이어 이동

Canvas 드래그 → 이동 거리 계산 → Animation Engine에 위치 변경 요청 → Project 데이터 갱신 → 새 화면 계산 → Canvas에 새 위치 표시

예시 2 · Timeline에서 레이어 길이 변경

막대 끝 드래그 → 새 시작·끝 프레임 계산 → Project Engine에 시간 배치 변경 요청 → 화면에 보이는 구간 갱신

예시 3 · Properties에서 회전값 입력

숫자 입력 → 입력값 검사 → Animation Engine에 회전 변경 요청 → 현재 프레임 값 다시 계산 → Canvas와 Timeline 표시 갱신
